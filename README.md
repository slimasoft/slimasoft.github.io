# SLIMASOFT

Site público em [https://slimasoft.github.io/](https://slimasoft.github.io/).

Cada aplicativo lançado ganha uma pasta em `aplicativos/<nome>/`, com a página do app e `privacidade/index.html`. A lista em `index.html` e `aplicativos/index.html` recebe um cartão novo. Hoje só o FTP Cliente está publicado.

Política do FTP Cliente: [https://slimasoft.github.io/aplicativos/ftp-cliente/privacidade/](https://slimasoft.github.io/aplicativos/ftp-cliente/privacidade/).
